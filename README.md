# Murb: app de música urbana (Android, iOS e Kotlin Multiplatform)

Trabalhei como desenvolvedor mobile freelancer na Murb, um app de música urbana (batalhas, beats, estúdio no app, chat), de dez/2022 a nov/2026, sem interrupções.

> O código é do cliente e privado. Esta página resume o meu trabalho.

## O que fiz
- 432 commits com meu nome; 4º de 46 autores.
- Ponta iOS do Kotlin Multiplatform: login com Apple, Google e Facebook, migração para Swift Package Manager, AdMob com App Tracking Transparency e controles de mídia nativos.
- Features em Compose Multiplatform (Configurações, Loja, convite por QR Code, nova Home) no padrão MVI.
- Deep links abertos por notificação push no Android e no iOS.
- No app Android anterior: VIP, BeatCoins e ranking.

## Stack
Kotlin · Kotlin Multiplatform · Compose Multiplatform · Ktor · MVI · Swift
